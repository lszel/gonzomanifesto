1. உருவாக்குநர் குறியீட்டின் ஒரு பகுதி: புறநிலையான உருவாக்கம் எதுவும் இல்லை. மென்பொருள் ஒரு கருவி அல்ல; அந்த நாளில் நிரலாளரின் மனநிலை, இரத்த அழுத்தம் மற்றும் கோபத்தின் இருமச் சுவடு.

2. குழப்பம் புனிதமானது: ஒரு அல்கோரிதம் மிகத் தெளிவாக இருந்தால் அது சந்தேகத்திற்குரியது. உண்மையான கோன்சோ குறியீடு ஒரு காட்டைப் போன்றது: ஆபத்தானது, இருண்டது, பொறிகள் எங்கே உள்ளன என்பதை அதன் படைப்பாளர் மட்டுமே அறிவார்.

3. உற்பத்தி சேவையகத்தில் சோதனை: Unit test என்பது கோழைகளுக்கும் அதிகாரிகளுக்கும் உரிய விளையாட்டு. உண்மையான கோன்சோ நிரலாளர் பயனர்களின் அலறல்களுக்கு நடுவே production-இல் debugging செய்கிறார்.

4. ஆவணப்படுத்தல் புனைவு: குறியீட்டின் comments விளக்கங்கள் அல்ல; உள் உரையாடல்கள், அரசியல் அறிக்கைகள் அல்லது உதவிக்கான அலறல்கள். குறியீட்டைப் புரியாதவர் அதைப் பயன்படுத்தத் தகுதியற்றவர்.

5. Pointer தான் தலைவர்: உங்களை கட்டுப்படுத்தாத நிரலாக்க மொழியைப் பயன்படுத்துங்கள்! நேரடி memory மேலாண்மை உங்கள் சுதந்திரத்தின் உத்தரவாதம். Safe type ஒரு சங்கிலி மட்டுமே. நாளை இல்லைபோல் memory address-களைப் பயன்படுத்துங்கள். Memory Leak யாரும் கேட்காத உங்கள் அலறல்.

6. கஃபீன் அடிப்படையிலான கட்டமைப்பு: குறியீட்டின் தரம் உட்கொண்ட தூண்டுபொருட்களின் அளவுக்கு நேர்விகிதமாகவும் தூக்க நேரத்திற்கு எதிர்விகிதமாகவும் இருக்கும்.

7. பிழைச் செய்தி ஒரு கலை: அது உதவாமல் அதிர்ச்சி அளிக்க வேண்டும். ஒவ்வொரு Runtime Error-இலும் இயந்திரத்தின் இகழ்ச்சியை பயனர் உணர வேண்டும்.

8. ஒருபோதும் சுத்தப்படுத்தாதீர்கள் (Refactor): மயக்க நிலையில் எழுதியது புனிதமானது. அதை “அழகாக்க” தொட்டால் மென்பொருளின் ஆன்மாவைக் கொல்வீர்கள்.

9. காலக்கெடு ஒரு பரிந்துரை மட்டுமே: கோன்சோ நிரலாளர் உத்வேகம் மற்றும் பதற்றத்தின் அலைகளில் பயணிக்கிறார். உருவாக்குநர் சரிந்தபோது குறியீடு முடிகிறது.

10. மென்பொருள் கணிக்க முடியாததாக இருக்க வேண்டும்: நல்ல கோன்சோ நிரலில் சிறிது சீரற்ற தன்மை இருக்கும். ஒவ்வொரு பொத்தான் அழுத்தத்திலும் ஒரேதே நடந்தால் அது தொழிற்துறைப் பொருள், கலை அல்ல.

11. பொறுப்பு? விலக்கப்பட்டது: உரிமத்தில் “இது இயங்கினால், அது உங்கள் பிரச்சினை” என்ற ஒரே விதி இருக்கட்டும். உருவாக்குநர் கடவுள் அல்ல; இயந்திரத்தின் அழிவுக்குச் சாட்சி.

12. வெளியேறும் தந்திரம்: திட்டம் சரிந்தால் விளக்கம் அளிக்காதீர்கள். Git history-ஐ அழித்து, hard drive-ஐ எரித்து, mobile signal இல்லாத மெக்சிகோ இடத்தைத் தேடுங்கள்.
