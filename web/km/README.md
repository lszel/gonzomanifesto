1. អ្នកអភិវឌ្ឍន៍គឺជាផ្នែកមួយនៃកូដ៖ គ្មានការអភិវឌ្ឍដែលមានអព្យាក្រឹតភាពទេ។ សូហ្វវែរមិនមែនជាឧបករណ៍ទេ ប៉ុន្តែជាស្នាមឌីជីថលនៃស្ថានភាពផ្លូវចិត្ត សម្ពាធឈាម និងកំហឹងរបស់អ្នកសរសេរកម្មវិធីនៅថ្ងៃនោះ។

2. ភាពច្របូកច្របល់គឺពិសិដ្ឋ៖ ប្រសិនបើអាល់ហ្គរីធម៍មួយច្បាស់ពេក វាគួរឱ្យសង្ស័យ។ កូដ gonzo ពិតប្រាកដដូចជាព្រៃជ្រៅ៖ គ្រោះថ្នាក់ ងងឹត ហើយមានតែអ្នកបង្កើតវាប៉ុណ្ណោះដែលដឹងថាអន្ទាក់នៅទីណា។

3. សាកល្បងលើម៉ាស៊ីនមេផលិតកម្ម៖ Unit test គឺជាកីឡារបស់មនុស្សកំសាក និងមន្ត្រីការិយាធិបតេយ្យ។ អ្នកសរសេរកម្មវិធី gonzo ពិតប្រាកដធ្វើ debugging ផ្ទាល់ក្នុងផលិតកម្ម កណ្ដាលសម្រែករបស់អ្នកប្រើប្រាស់។

4. ឯកសារគឺជារឿងប្រឌិត៖ មតិយោបល់ភ្ជាប់នឹងកូដមិនមែនជាការពន្យល់ទេ ប៉ុន្តែជាការនិយាយក្នុងចិត្ត សេចក្តីប្រកាសនយោបាយ ឬសម្រែកសុំជំនួយ។ អ្នកដែលមិនយល់កូដ មិនសមនឹងប្រើវាទេ។

5. Pointer គឺជាម្ចាស់៖ ប្រើភាសាសរសេរកម្មវិធីដែលមិនដាក់កម្រិតលើអ្នក! ការគ្រប់គ្រងអង្គចងចាំដោយផ្ទាល់គឺជាការធានាសេរីភាពរបស់អ្នក។ ការប្រើប្រភេទដែលមានសុវត្ថិភាពគ្រាន់តែជាច្រវាក់។ ប្រើអាសយដ្ឋានអង្គចងចាំដូចជាគ្មានថ្ងៃស្អែក។ Memory Leak គឺជាសម្រែករបស់អ្នកដែលគ្មាននរណាឮ។

6. ស្ថាបត្យកម្មផ្អែកលើកាហ្វេអ៊ីន៖ គុណភាពកូដសមាមាត្រផ្ទាល់នឹងបរិមាណសាររំញោចដែលបានប្រើ និងសមាមាត្រច្រាសនឹងចំនួនម៉ោងដែលបានចំណាយលើការគេង។

7. សារកំហុសជាសិល្បៈ៖ សារកំហុសមិនគួរជួយទេ ប៉ុន្តែគួរធ្វើឱ្យភ្ញាក់ផ្អើល។ អ្នកប្រើប្រាស់ត្រូវមានអារម្មណ៍ពីការមើលងាយរបស់ម៉ាស៊ីន និងអ្នកបង្កើតវា នៅរាល់ Runtime Error។

8. កុំសម្អាតឡើយ (Refactor)៖ អ្វីដែលអ្នកបានសរសេរម្តងក្នុងស្ថានភាពស្រមើស្រមៃគឺពិសិដ្ឋ។ ប្រសិនបើអ្នកប៉ះវាដើម្បីធ្វើឱ្យ “ស្អាតជាងមុន” អ្នកនឹងសម្លាប់ព្រលឹងរបស់សូហ្វវែរ។

9. កាលកំណត់គ្រាន់តែជាសំណើ៖ អ្នកសរសេរកម្មវិធី gonzo មិនធ្វើការតាមនាឡិកាទេ ប៉ុន្តែជិះលើរលកនៃការបំផុសគំនិត និងភាពភ័យស្លន់ស្លោ។ កូដរួចរាល់នៅពេលអ្នកអភិវឌ្ឍន៍ដួលរលំ។

10. សូហ្វវែរត្រូវតែមិនអាចទស្សន៍ទាយបាន៖ កម្មវិធី gonzo ល្អតែងតែមានភាពចៃដន្យបន្តិច។ ប្រសិនបើរាល់ការចុចប៊ូតុងមានរឿងដូចគ្នាកើតឡើង វាគឺជាផលិតផលឧស្សាហកម្មគួរឱ្យធុញ មិនមែនជាសិល្បៈទេ។

11. ទំនួលខុសត្រូវ? មិនរាប់បញ្ចូល៖ កិច្ចព្រមព្រៀងអាជ្ញាបណ្ណគួរមានតែមួយចំណុច៖ “ប្រសិនបើវាដំណើរការ នោះជាបញ្ហារបស់អ្នក។” អ្នកអភិវឌ្ឍន៍មិនមែនជាព្រះទេ គ្រាន់តែជាសាក្សីនៃការបំផ្លាញម៉ាស៊ីន។

12. យុទ្ធសាស្ត្រចាកចេញ៖ នៅពេលគម្រោងដួលរលំ កុំពន្យល់។ លុបប្រវត្តិ Git ដុតថាសរឹង ហើយស្វែងរកកន្លែងមួយនៅម៉ិកស៊ិកដែលគ្មានសញ្ញាទូរស័ព្ទ។
