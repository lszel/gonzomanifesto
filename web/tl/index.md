1. Ang developer ay bahagi ng code: Walang obhetibong development. Ang software ay binary imprint ng kalagayan ng isip, presyon ng dugo, at galit ng programmer sa araw na iyon.

2. Banal ang kaguluhan: Kapag napakalinaw ng algorithm, kahina-hinala ito. Ang tunay na gonzo code ay parang gubat: mapanganib, madilim, at ang lumikha lamang ang nakaaalam kung nasaan ang mga bitag.

3. Pagsubok sa production server: Ang Unit test ay laro ng mga duwag at burukrata. Ang tunay na gonzo programmer ay nagde-debug sa production, sa gitna ng sigaw ng mga user.

4. Kathang-isip ang dokumentasyon: Ang comments ay hindi paliwanag kundi panloob na monologo, pampolitikang manipesto, o sigaw ng tulong. Ang hindi nakauunawa sa code ay hindi karapat-dapat gumamit nito.

5. Ang pointer ang panginoon: Gumamit ng wikang hindi naglilimita sa iyo! Ang direktang memory management ang garantiya ng kalayaan. Ang safe type ay tanikala lamang. Gamitin ang memory address na parang walang bukas. Ang Memory Leak ang sigaw mong walang nakaririnig.

6. Arkitekturang nakabatay sa caffeine: Ang kalidad ng code ay tuwirang proporsyonal sa stimulant at baligtad na proporsyonal sa oras ng tulog.

7. Error message bilang sining: Hindi ito dapat tumulong kundi gumulat. Dapat maramdaman ng user ang paghamak ng makina sa bawat Runtime Error.

8. Huwag kailanman maglinis (Refactor): Banal ang isinulat sa trance. Kapag ginalaw upang maging “mas maganda,” pinapatay mo ang kaluluwa ng software.

9. Ang deadline ay mungkahi lamang: Sumasakay ang gonzo programmer sa alon ng inspirasyon at panic. Tapos ang code kapag bumagsak ang developer.

10. Dapat hindi mahulaan ang software: May kaunting randomness ang mahusay na gonzo program. Kung pareho lagi ang nangyayari, industriyal na produkto iyon, hindi sining.

11. Pananagutan? Hindi kasama: Dapat sabihin lamang ng lisensya: “Kung umandar, problema mo iyon.” Hindi Diyos ang developer, saksi lamang sa pagkasira ng makina.

12. Exit strategy: Kapag bumagsak ang proyekto, huwag magpaliwanag. Burahin ang Git history, sunugin ang hard drive, at humanap ng lugar sa Mexico na walang mobile signal.
