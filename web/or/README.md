1. ବିକାଶକାରୀ କୋଡର ଏକ ଅଂଶ: ନିରପେକ୍ଷ ବିକାଶ ବୋଲି କିଛି ନାହିଁ। ସଫ୍ଟୱେର ଏକ ଉପକରଣ ନୁହେଁ, ବରଂ ସେହି ଦିନ ପ୍ରୋଗ୍ରାମରଙ୍କ ମନୋଦଶା, ରକ୍ତଚାପ ଏବଂ କ୍ରୋଧର ବାଇନାରି ଛାପ।

2. ଅବ୍ୟବସ୍ଥା ପବିତ୍ର: ଯଦି ଏକ ଆଲଗୋରିଦମ ଅତ୍ୟଧିକ ସ୍ପଷ୍ଟ, ତେବେ ତାହା ସନ୍ଦେହଜନକ। ପ୍ରକୃତ ଗୋଞ୍ଜୋ କୋଡ ଜଙ୍ଗଲ ପରି: ବିପଦଜନକ, ଅନ୍ଧକାର, ଏବଂ ଫାନ୍ଦ କେଉଁଠି ଅଛି ତାହା କେବଳ ତାହାର ସୃଷ୍ଟିକର୍ତ୍ତା ଜାଣନ୍ତି।

3. ପ୍ରୋଡକ୍ସନ ସର୍ଭରରେ ପରୀକ୍ଷା: Unit test ଭୀରୁ ଏବଂ ନିୟମତନ୍ତ୍ରୀଙ୍କ ଖେଳ। ପ୍ରକୃତ ଗୋଞ୍ଜୋ ପ୍ରୋଗ୍ରାମର ବ୍ୟବହାରକାରୀଙ୍କ ଚିତ୍କାର ମଧ୍ୟରେ ସିଧାସଳଖ ପ୍ରୋଡକ୍ସନରେ debugging କରନ୍ତି।

4. ଡକ୍ୟୁମେଣ୍ଟେସନ କଳ୍ପନା: କୋଡ ସହିତ ଯୋଡ଼ାଯାଇଥିବା comment ବ୍ୟାଖ୍ୟା ନୁହେଁ, ବରଂ ଆଭ୍ୟନ୍ତରୀଣ ଏକାଳାପ, ରାଜନୈତିକ ଘୋଷଣାପତ୍ର କିମ୍ବା ସାହାଯ୍ୟର ଚିତ୍କାର। ଯିଏ କୋଡ ବୁଝେ ନାହିଁ, ସେ ଏହା ବ୍ୟବହାର କରିବାକୁ ଯୋଗ୍ୟ ନୁହେଁ।

5. Pointer ହେଉଛି ମାଲିକ: ଏମିତି ପ୍ରୋଗ୍ରାମିଂ ଭାଷା ବ୍ୟବହାର କରନ୍ତୁ ଯାହା ଆପଣଙ୍କୁ ସୀମିତ କରେ ନାହିଁ! ସିଧାସଳଖ memory ପରିଚାଳନା ଆପଣଙ୍କ ସ୍ୱାଧୀନତାର ନିଶ୍ଚୟତା। Safe type ବ୍ୟବହାର କେବଳ ଏକ ବନ୍ଧନ। ଆସନ୍ତାକାଲି ନାହିଁ ଭଳି memory address ବ୍ୟବହାର କରନ୍ତୁ। Memory Leak ହେଉଛି ଆପଣଙ୍କ ଚିତ୍କାର ଯାହା କେହି ଶୁଣେ ନାହିଁ।

6. କାଫେଇନ-ଆଧାରିତ ଆର୍କିଟେକ୍ଚର: କୋଡର ଗୁଣବତ୍ତା ଗ୍ରହଣ କରାଯାଇଥିବା ଉତ୍ତେଜକର ପରିମାଣ ସହିତ ସିଧାସଳଖ ଏବଂ ଶୋଇବାରେ ବ୍ୟୟିତ ଘଣ୍ଟା ସହିତ ବିପରୀତ ଅନୁପାତରେ ଥାଏ।

7. Error message କଳା ଭାବରେ: Error message ସାହାଯ୍ୟ କରିବା ଉଚିତ ନୁହେଁ, ବରଂ ଆଘାତ ଦେବା ଉଚିତ। ପ୍ରତ୍ୟେକ Runtime Error ସମୟରେ ବ୍ୟବହାରକାରୀ ଯନ୍ତ୍ର ଏବଂ ତାହାର ସୃଷ୍ଟିକର୍ତ୍ତାଙ୍କ ଅବମାନନା ଅନୁଭବ କରିବା ଉଚିତ।

8. କେବେ ସଫା କରନ୍ତୁ ନାହିଁ (Refactor): ଟ୍ରାନ୍ସ ଅବସ୍ଥାରେ ଆପଣ ଥରେ ଯାହା ଲେଖିଥିଲେ ତାହା ପବିତ୍ର। ଏହାକୁ “ଅଧିକ ସୁନ୍ଦର” କରିବା ପାଇଁ ଛୁଇଁଲେ ସଫ୍ଟୱେରର ଆତ୍ମାକୁ ହତ୍ୟା କରିବେ।

9. ସମୟସୀମା କେବଳ ଏକ ପରାମର୍ଶ: ଗୋଞ୍ଜୋ ପ୍ରୋଗ୍ରାମର ଘଡ଼ି ଅନୁସାରେ କାମ କରନ୍ତି ନାହିଁ, ବରଂ ପ୍ରେରଣା ଏବଂ ଆତଙ୍କର ତରଙ୍ଗରେ ଚାଲନ୍ତି। ବିକାଶକାରୀ ଭାଙ୍ଗିପଡ଼ିଲେ କୋଡ ପ୍ରସ୍ତୁତ ହୁଏ।

10. ସଫ୍ଟୱେର ଅନୁମାନଯୋଗ୍ୟ ନ ହେବା ଉଚିତ: ଭଲ ଗୋଞ୍ଜୋ ପ୍ରୋଗ୍ରାମରେ ସବୁବେଳେ କିଛି ଅନିୟମିତତା ଥାଏ। ପ୍ରତ୍ୟେକ button ଦବାଇଲେ ଯଦି ସମାନ ଘଟଣା ଘଟେ, ତେବେ ତାହା ଏକ ବିରକ୍ତିକର ଶିଳ୍ପ ଉତ୍ପାଦ, କଳା ନୁହେଁ।

11. ଦାୟିତ୍ୱ? ବାଦ: License agreement ରେ କେବଳ ଗୋଟିଏ ଧାରା ରହିବା ଉଚିତ: “ଯଦି ଏହା ଚାଲେ, ତେବେ ଏହା ଆପଣଙ୍କ ସମସ୍ୟା।” ବିକାଶକାରୀ ଭଗବାନ ନୁହେଁ, କେବଳ ଯନ୍ତ୍ରର ବିନାଶର ସାକ୍ଷୀ।

12. ପ୍ରସ୍ଥାନ କୌଶଳ: ପ୍ରକଳ୍ପ ଭାଙ୍ଗିପଡ଼ିଲେ ବ୍ୟାଖ୍ୟା କରନ୍ତୁ ନାହିଁ। Git history ମିଟାନ୍ତୁ, hard drive ପୋଡ଼ନ୍ତୁ ଏବଂ mobile signal ନଥିବା ମେକ୍ସିକୋର ଏକ ସ୍ଥାନ ଖୋଜନ୍ତୁ।
