1. ገንቢው የኮዱ አካል ነው፦ ገለልተኛ ልማት የለም። ሶፍትዌር መሣሪያ ሳይሆን በዚያ ቀን የፕሮግራመሩን የአእምሮ ሁኔታ፣ የደም ግፊት እና ቁጣ የሚያሳይ ሁለትዮሽ አሻራ ነው።

2. ትርምስ ቅዱስ ነው፦ አልጎሪዝም ከመጠን በላይ ግልጽ ከሆነ አጠራጣሪ ነው። እውነተኛ የጎንዞ ኮድ እንደ ጫካ ነው፦ አደገኛ፣ ጨለማ፣ እና ወጥመዶቹ የት እንዳሉ የሚያውቀው ፈጣሪው ብቻ ነው።

3. በምርት ሰርቨር ላይ መፈተሽ፦ Unit test የፈሪዎችና የቢሮክራቶች ስፖርት ነው። እውነተኛው የጎንዞ ፕሮግራመር በተጠቃሚዎች ጩኸት መካከል በቀጥታ በምርት ላይ ስህተት ያርማል።

4. ሰነድ ልብ ወለድ ነው፦ በኮድ ላይ የተጨመሩ አስተያየቶች ማብራሪያዎች ሳይሆኑ ውስጣዊ ንግግሮች፣ ፖለቲካዊ ማኒፌስቶዎች ወይም የእርዳታ ጩኸቶች ናቸው። ኮዱን የማይረዳ ሰው ሊጠቀምበት አይገባውም።

5. ጠቋሚው (pointer) ጌታ ነው፦ የማይገድቡህን የፕሮግራሚንግ ቋንቋ ተጠቀም! ቀጥተኛ የማስታወሻ አስተዳደር የነፃነትህ ዋስትና ነው። ደህንነታቸው የተጠበቁ ዓይነቶችን መጠቀም ሰንሰለት ብቻ ነው። ነገ እንደሌለ የማስታወሻ አድራሻዎችን ተጠቀም። Memory Leak ማንም የማይሰማው ጩኸትህ ነው።

6. በካፌይን የተመሠረተ አርክቴክቸር፦ የኮዱ ጥራት ከተወሰዱት አነቃቂ ንጥረ ነገሮች መጠን ጋር ቀጥተኛ፣ በእንቅልፍ ከተወሰዱት ሰዓታት ብዛት ጋር ደግሞ ተቃራኒ ግንኙነት አለው።

7. የስህተት መልዕክት እንደ ጥበብ፦ የስህተት መልዕክቱ አያግዝ፤ ይልቁንም ያስደንግጥ። ተጠቃሚው በእያንዳንዱ Runtime Error ጊዜ የማሽኑንና የፈጣሪውን ንቀት ሊሰማው ይገባል።

8. በፍጹም አታጽዳ (Refactor)፦ በትራንስ ሁኔታ አንድ ጊዜ የጻፍከው ቅዱስ ነው። “ይበልጥ ቆንጆ” ለማድረግ ከነካኸው የሶፍትዌሩን ነፍስ ትገድላለህ።

9. የመጨረሻ ጊዜው ጥቆማ ብቻ ነው፦ የጎንዞ ፕሮግራመር በሰዓት አይሠራም፤ በመነሳሳትና በድንጋጤ ማዕበል ላይ ይጋልባል። ኮዱ የሚያልቀው ገንቢው ሲወድቅ ነው።

10. ሶፍትዌሩ የማይገመት ይሁን፦ ጥሩ የጎንዞ ፕሮግራም ሁልጊዜ ትንሽ የዘፈቀደነት አለው። ቁልፍ በተጫነ ቁጥር ተመሳሳይ ነገር ከተከሰተ፣ አሰልቺ የኢንዱስትሪ ምርት ነው እንጂ ጥበብ አይደለም።

11. ኃላፊነት? አይካተትም፦ የፈቃድ ስምምነቱ አንድ ነጥብ ብቻ ይኑረው፦ “ከተነሳ፣ ያ የአንተ ችግር ነው።” ገንቢው እግዚአብሔር አይደለም፤ ማሽኑ ሲጠፋ የሚመለከት ምስክር ብቻ ነው።

12. የመውጫ ስልት፦ ፕሮጀክቱ ሲወድቅ ማብራሪያ አትስጥ። የGit ታሪኩን ሰርዝ፣ ሃርድ ዲስኩን አቃጥል፣ እና በሜክሲኮ የሞባይል ምልክት የሌለበትን ቦታ ፈልግ።
