1. Olùdàgbàsókè jẹ́ apá kan kóòdù: Kò sí ìdàgbàsókè tí kò ní ipa ẹni. Software jẹ́ àmì binary ti ipò ọkàn, titẹ ẹ̀jẹ̀ àti ìbínú programmer.

2. Rògbòdìyàn jẹ́ mímọ́: Algorithm tí ó hàn gbangba jù ń fa iyèméjì. Gonzo code dàbí igbó: ó léwu, ó ṣókùnkùn, ẹlẹ́dàá rẹ̀ nikan ló mọ ibi ìdẹ̀.

3. Ìdánwò lórí production server: Unit test jẹ́ eré àwọn ọlọ̀lẹ̀ àti bureaucrat. Gonzo programmer máa ń ṣe debugging ní production láàárín igbe àwọn user.

4. Documentation jẹ́ ìtàn: Comments kì í ṣe àlàyé, wọ́n jẹ́ ọ̀rọ̀ inú, manifesto òṣèlú tàbí igbe ìrànlọ́wọ́. Ẹni tí kò lóye kóòdù kò yẹ láti lò ó.

5. Pointer ni olúwa: Lo èdè tí kò fi ààlà sí ọ! Direct memory management ni ìdánilójú òmìnira. Safe type jẹ́ ẹ̀wọ̀n. Memory Leak ni igbe rẹ tí kò sí ẹni tó gbọ́.

6. Architecture tó dá lórí caffeine: Didara kóòdù ń pọ̀ pẹ̀lú stimulant, ó sì dínkù pẹ̀lú wákàtí oorun.

7. Error message gẹ́gẹ́ bí iṣẹ́ ọnà: Kò gbọdọ̀ ràn lọ́wọ́, ó gbọdọ̀ ya ènìyàn lẹ́nu. User gbọdọ̀ ní ìmọ̀lára ẹ̀gàn ẹrọ ní gbogbo Runtime Error.

8. Má ṣe sọ di mímọ́ láéláé (Refactor): Ohun tí o kọ ní trance jẹ́ mímọ́. Tí o bá ṣe é “lẹ́wà síi,” o pa ẹ̀mí software.

9. Deadline jẹ́ àbá nìkan: Gonzo programmer ń gun ìgbì ìmísí àti ìbẹ̀rù. Kóòdù parí nígbà tí developer bá ṣubú.

10. Software gbọdọ̀ jẹ́ aláìlérò: Gonzo program dáadáa ní randomness. Tí ohun kan náà bá ń ṣẹlẹ̀, ọja ilé-iṣẹ́ ni, kì í ṣe iṣẹ́ ọnà.

11. Ìdáhùn? A yọ ọ́: License sọ pé: “Tí ó bá bẹ̀rẹ̀, ìṣòro rẹ ni.” Developer kì í ṣe Ọlọ́run, ẹlẹ́rìí ìparun ẹrọ ni.

12. Ọ̀nà ìjáde: Nígbà tí project bá ṣubú, má ṣe ṣàlàyé. Pa Git history, sun hard drive, kí o sì rí ibi ní Mexico tí kò ní mobile signal.
